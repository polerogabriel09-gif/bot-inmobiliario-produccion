MEMORIA DE PROYECTO CORREGIDA

Ahora el proyecto queda fijo por número de WhatsApp.

Ejemplo:
Cliente: Me interesa Palmeras San Miguel
Cliente: ¿Dónde queda?
=> ubicación de Palmeras.

Cliente: ¿Y las cuotas?
=> cotizaciones de Palmeras.

Cliente: Mándame fotos
=> fotos de Palmeras.

NO cambia de proyecto hasta que el cliente mencione explícitamente otro.

Además, las ubicaciones ya no pasan por la IA:
se responden directamente usando el proyecto guardado en memoria.

INSTALACIÓN:
1. Conserva tu .env.
2. Reemplaza app.py.
3. Conserva la carpeta media.
4. Ctrl + C
5. python app.py
