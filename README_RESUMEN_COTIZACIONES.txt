VERSION: RESUMEN + TODAS LAS COTIZACIONES

CUANDO EL CLIENTE PREGUNTA:
- precio / precios
- cuánto cuesta / cuánto vale
- cuotas
- cotización / cotizaciones
- mensualidades
- financiamiento
- plan de pagos

EL BOT HACE ESTO:

1. Envía un resumen comercial con:
   - precio desde
   - enganche desde
   - cuota desde
   - financiamiento
   - medidas/fases
   - amenidades
   - servicios
   - ubicación
   - Google Maps

2. Envía TODAS las imágenes de cotización del proyecto activo.

3. Envía un cierre:
   "Si alguna de estas opciones te interesa, puedo ayudarte a coordinar una visita al proyecto 📆🏡"

NO vuelve a preguntar medida.
NO vuelve a preguntar proyecto si ya estaba activo.
NO pregunta si quiere cotización porque ya se la mandó.

EJEMPLO VISTA HERMOSA:
Cliente: ¿Qué precios tienen?
Bot: resumen Vista Hermosa
Bot: cotización Fase F
Bot: cotización Fase G
Bot: CTA visita

INSTALACION:
1. Conserva tu .env.
