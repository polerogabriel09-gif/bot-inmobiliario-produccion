CORRECCION VISTA HERMOSA + APARTADO DE AMENIDADES

1. VISTA HERMOSA
- Se quitaron del envío automático las fotos generales antiguas de Vista Hermosa.
- Si un cliente pide fotos, imágenes o videos de Vista Hermosa, se envían únicamente
  los videos de Vista Hermosa cargados en media/videos/vista_hermosa/.
- Las fotos antiguas pueden seguir dentro de media/vista_hermosa/, pero el bot ya no
  las utiliza automáticamente.

2. PRECIOS / COTIZACIONES
- Después de enviar precios/cotizaciones, el bot YA NO manda fotos/videos generales
  del proyecto.
- Ese apartado visual manda EXCLUSIVAMENTE el paquete de amenidades:
  fotos de media/amenidades/ + videos de media/videos/general/.
- Así no se mezclan calles, lotes o recorridos generales con el bloque de amenidades.

3. SOLICITUD DIRECTA DE FOTOS/VIDEOS
- Palmeras y Buenaventura mantienen fotos + videos + amenidades.
- Vista Hermosa usa solo videos del proyecto + el paquete de amenidades.

El archivo .env no se incluye ni se modifica.
