BOT INMOBILIARIO - FLUJO SIMPLE DE PRECIOS

NUEVO COMPORTAMIENTO:

Si el cliente pregunta:
- precio / precios
- cuánto cuesta / cuánto vale
- costo
- cotización
- cuotas
- mensualidades
- financiamiento
- enganche

Y YA se sabe de qué proyecto está hablando:

1. El bot manda una explicación BREVE del proyecto.
2. Incluye amenidades y servicios.
3. NO escribe precios ni cuotas en el mensaje.
4. Inmediatamente manda TODAS las imágenes reales de cotización
   disponibles del proyecto.
5. No pregunta medida.
6. No pregunta fase.
7. No pregunta nuevamente el proyecto.
8. Termina con un CTA corto para avanzar a visita o siguiente paso.

EJEMPLO:

Cliente:
"Me interesa Palmeras San Miguel"

Cliente:
"¿Qué precios tienen?"

Bot:
[breve explicación de Palmeras + amenidades + servicios]
[imagen cotización 8x16 Fase 1]
[imagen cotización 8x16 Fase 2]
[imagen cotización 8x18 Fase 1]
[imagen cotización 8x18 Fase 2]
[CTA corto]

IMPORTANTE:
Conserva tu .env actual.

INSTALACIÓN:
1. Reemplaza app.py.
2. Copia/reemplaza la carpeta media completa.
3. Ctrl + C
4. python app.py
