CORRECCIONES

1. XOCHI
"¿Puedo irme por la Xochi?"
ya NO se interpreta como solicitud de visita.
Ahora responde la ruta y envía automáticamente el tarifario Xochi.

2. CUOTAS ESPECIFICAS
"¿Cuánto es la cuota a 7 años?"
ya NO vuelve a mandar toda la cotización.
Responde únicamente los montos correspondientes a ese plazo.

Si hay varias fases/medidas, muestra una línea por opción.

Ejemplos:
Vista Hermosa, 7 años:
- 8x16 Fase F: Q1,578
- 8x16 Fase G: Q1,708

El financiamiento se aclara como propio y directo con la empresa.

INSTALACION
1. Conserva tu .env.
2. Reemplaza app.py.
3. Copia la carpeta media del ZIP si aún no tienes el tarifario Xochi.
4. Ctrl + C
5. python app.py
