CAMBIO: FINANCIAMIENTO PROPIO

Ahora el bot sabe de forma explícita que:
- El financiamiento es propio y directo con la empresa.
- No se trabaja con ningún banco.

Si preguntan:
"¿Con qué banco trabajan?"
responde directamente que no se trabaja con bancos.

Además, cuando el bot hable de:
- financiamiento
- cuotas
- plazos
- precios financiados

debe mencionar naturalmente que el financiamiento es propio.

No modifica el resto de funciones:
cotizaciones, audios, fotos, videos, visitas, cierre de citas,
punto de encuentro, requisitos y gastos adicionales.

INSTALACION:
1. Conserva .env
2. Conserva media
3. Reemplaza app.py
4. Ctrl + C
5. python app.py
