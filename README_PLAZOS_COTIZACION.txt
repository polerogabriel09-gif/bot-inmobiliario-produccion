NUEVO: PLAZOS DISPARAN COTIZACION

Ahora cualquier mención de plazo de financiamiento envía inmediatamente
las imágenes de cotización del proyecto activo.

Ejemplos:
- ¿Y a 2 años?
- ¿Cuánto queda a 6 años?
- El de 8 años
- ¿A 24 meses?
- ¿A 96 meses?

No necesita que el bot haya ofrecido la cotización antes.
No pregunta de nuevo si quiere verla.

Se mantienen todas las funciones anteriores.

INSTALACION:
1. Conserva .env
2. Conserva media
3. Reemplaza app.py
4. Ctrl + C
5. python app.py
