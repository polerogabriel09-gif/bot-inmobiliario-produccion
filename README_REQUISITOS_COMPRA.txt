ACTUALIZACION - REQUISITOS DE COMPRA

CLIENTE EN ESTADOS UNIDOS / EXTRANJERO
- DPI o pasaporte.
- Gestor de negocios en Guatemala (familiar o conocido).
- Copia de remesa o forma de pago.
- Se recuerda que hay financiamiento propio.
- El bot explica ventajas de avanzar desde el extranjero.
- Termina con CTA para revisar proyecto y plan de pago.

CLIENTE EN GUATEMALA
- DPI.
- Recibo de luz o agua.
- Constancia de ingresos (contador o estados de cuenta).
- También se recuerda financiamiento propio.
- Termina con CTA para avanzar.

El bot detecta si el cliente ya había dicho antes que vive en el extranjero
y mantiene ese contexto usando el historial.

INSTALACION:
1. Conserva .env.
2. Conserva media.
3. Reemplaza app.py.
4. Ctrl + C
5. python app.py
