CAMBIO: COTIZACION + FOTOS + VIDEOS + AMENIDADES

1. Cuando el cliente pide precio/cotizacion/cuotas:
   - se envia el resumen del proyecto;
   - se envian las cotizaciones correspondientes;
   - se envian fotos y videos del proyecto;
   - se envian tambien fotos y videos de amenidades.

2. Cuando el cliente pide fotos O videos:
   - se envian fotos y videos del proyecto;
   - se envian tambien fotos y videos de amenidades.

3. Paquete de amenidades:
   - hasta 3 fotos relacionadas con amenidades;
   - hasta 3 videos de amenidades ya existentes en media/videos/general;
   - se eliminan duplicados dentro del paquete para evitar repeticiones excesivas.

4. No se modifica .env.
