NUEVO: PUNTO DE ENCUENTRO

Si el cliente pregunta:
- ¿Dónde nos podemos juntar?
- ¿Dónde nos vemos?
- ¿Cuál sería el punto de encuentro?

El bot:
1. Sugiere primero encontrarse directamente en el proyecto.
2. Sugiere un punto alternativo cercano cuando está cargado.
3. Permite al cliente proponer otro lugar.
4. No repite precios, cotizaciones ni financiamiento.

Sugerencias:
- Palmeras San Miguel -> Centro Comercial La Trinidad.
- Buenaventura Cuyotenango -> Parque Central de Cuyotenango.
- Vista Hermosa -> directamente en el proyecto, CA-2 km 188; o un punto cercano sobre la ruta.

INSTALACION:
1. Conserva .env
2. Conserva media
3. Reemplaza app.py
4. Ctrl + C
5. python app.py
